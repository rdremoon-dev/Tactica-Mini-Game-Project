# Tactica-Mini-Game-Project:
------------------------------
A clean and interactive browser-based strategy mini game built with HTML, CSS, and JavaScript. Designed to demonstrate core front-end development skills, including DOM manipulation, game logic,and responsive UI design.
Description:
------------
Tactica is a lightweight web-based game project developed as part of my JavaScript learning journey. The goal of this project was to strengthen my understanding of DOM manipulation, event handling, and game logic implementation.
The game features a simple yet engaging interface where users can interact with elements dynamically. It focuses on clean UI, smooth user experience, and structured JavaScript logic.

This project showcases my ability to:
--------------------------------------
Build interactive UI components
Implement game logic from scratch
Handle user events effectively
Structure code in a readable and maintainable way
